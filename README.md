# BioMed Expo x Alien Event — Landing Page Concept

Static concept redesign for BioMed Expo and Alien Event (Las Vegas, Oct 16–18, 2026), prepared by Harshal Kadam as a free proposal. Not the official event website.

**Live demo:** https://harshalkadam79.github.io/biomed-expo-demo/

## Structure
```
index.html        # entry point
css/style.css     # all styles (responsive, BioMed/Alien x Day/Night themes)
js/main.js        # portal slider, countdown, pass picker, speakers, map lightbox, Riley chat assistant
images/           # logo, exhibit hall map, Bizton logo
```

Pure HTML/CSS/JS — no build step, no backend. Deployed with GitHub Pages (branch `main`, folder `/`).
